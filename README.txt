TVMovies iOS wrapper starter (not a compiled IPA)

This starter is configured to load your existing website:
https://playtvmoviesformobile.duckdns.org/

App name: TVMovies
Bundle ID: com.tvmovies.mobile
Icon concept: assets/tvmovies-icon.png

IMPORTANT:
- This ZIP is source/configuration only. It is NOT an IPA and cannot be imported into LiveContainer yet.
- You can prepare the Capacitor project on Windows, but building/signing the iOS app requires a macOS/Xcode build environment (a trusted cloud Mac runner is an option).
- Before distributing the IPA, configure the generated iOS app's icon assets using assets/tvmovies-icon.png, then build/sign it.
- Capacitor's server.url is configured to load the live website; the app therefore requires internet access.
